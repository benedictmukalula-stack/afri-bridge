## HOW TO UPLOAD TO BUILDER.IO

### Step 1: Access Asset Library

```
1. Open your Builder.io project
2. Navigate to Content → Assets
3. Click "Upload" or "Add Asset"
```

### Step 2: Upload Images

**Option A: Direct Upload from URL**

```
1. Select "Add from URL"
2. Paste image URL from this document
3. Builder will fetch and optimize automatically
```

**Example:**
```
https://images.pexels.com/photos/36060451/pexels-photo-36060451.jpeg
```

**Option B: Download and Upload**

```
1. Right-click image URL → "Save image as"
2. Save with semantic name (e.g., afribridge-hero-port-sunset.webp)
3. Upload to Builder Asset Library
```

### Step 3: Configure Image Settings in Builder

Once uploaded, for each image:

```
Image Settings:
  ✓ Lazy loading: ENABLED
  ✓ Responsive images: ENABLED
  ✓ Format: WEBP (Builder auto-optimizes)
  ✓ Alt text: Copy from this document
  ✓ Object fit: COVER (for hero/section)
  ✓ Border radius: 12px (for premium feel)
```

### Step 4: Insert into Sections

**For Hero Section (Left-to-Right Layout):**

```
Hero Section
  ├─ Row
  │   ├─ Column 1 (60% width)
  │   │   └─ Text Block
  │   │       └─ Headline, subheadline, CTA
  │   └─ Column 2 (40% width)
  │       └─ Image Block
  │           └─ afribridge-hero-port-sunset.webp
  └─ Overlay: rgba(11,31,58,0.25) [transparent navy]
```

**For Services Alternating Layout:**

```
Services Section
  ├─ Service 1
  │   ├─ Column 1: Text + Details
  │   └─ Column 2: afribridge-service-ocean-freight.webp
  ├─ Service 2
  │   ├─ Column 1: afribridge-service-air-freight.webp
  │   └─ Column 2: Text + Details
  └─ [Continue alternating...]
```

**For Industries Grid:**

```
Industries Section
  ├─ Industry Card 1
  │   └─ Image: afribridge-industry-mining.webp

  ├─ Industry Card 2
```
