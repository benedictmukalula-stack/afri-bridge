## Image Optimization Guidelines

### Formats & Compression

```
Format: WebP (primary), JPEG (fallback)
Quality: 80
Max file size hero: 300KB
Max file size section: 150KB
Max file size card: 80KB
```

### Responsive Image Sizes

```
Mobile (375px): 375w
Tablet (768px): 768w
Desktop (1200px): 1200w
Large desktop (1920px): 1920w
```

### Next.js Image Implementation

```jsx
import Image from 'next/image';

<Image
  src="/images/afribridge-hero-african-port-sunset.webp"
  alt="African port with container cranes at sunset"
  width={2000}
  height={1125}
  priority
  sizes="(max-width: 768px) 100vw, (max-width: 1200px) 90vw, 1920px"
  style={{ objectFit: 'cover' }}
/>
```
